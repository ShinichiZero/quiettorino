# QuietTorino

Progressive Web App accessibile per consultare le caratteristiche sensoriali degli spazi pubblici di Torino.

## Requisiti

- Node.js 20.9 o versione successiva
- npm 10 o versione successiva

## Comandi

```bash
npm install
npm run dev
npm run typecheck
npm run lint
npm run build
```

I dati in `data/mockSpaces.ts` sono stime editoriali orientative e non misurazioni certificate. Prima di uno spostamento è necessario verificare orari, servizi e accessibilità presso la struttura interessata.
